# 결정 사항

두 사람이 합의한 결정을 날짜순으로 남긴다. 설계서(수정본 계획서)와 달라지는 결정은 "설계서와 다름"에 표시하고, 최종 보고서의 "계획 대비 바뀐 점"에 옮긴다.

| 날짜 | 결정 | 이유 | 설계서와 다름 |
|---|---|---|---|
| 11/22 | `SyntaxIssue`에 `offset`(0부터 센 글자 위치)을 추가한다 | 커서 이동과 색 표시 층은 offset을 쓰므로 줄·열에서 다시 계산하지 않도록 함께 담는다 | 예 |
| 11/22 | 다시 실행은 Ctrl+Y만 쓴다. Cmd+Shift+Z·Ctrl+Shift+Z는 다시 실행으로 쓰지 않고 브라우저 기본 동작만 막는다 | FR-23은 Ctrl+Y만 정했다. 막지 않으면 브라우저 자체 다시 실행이 Undo 기록과 본문을 어긋나게 한다 | 아니요 |
| 11/22 | 로직 클래스는 `src/logic/`에 둔다 | 화면 컴포넌트(`src/components/`)와 나눠 단위 테스트하기 쉽게 한다 | 아니요 |
| 11/22 | 편집 영역 글꼴은 나눔고딕코딩(Nanum Gothic Coding), 14px, 줄 간격 20px, tab-size 4로 한다 (점검에서 확정 필요) | 아래 "편집 영역 글꼴" 참고 | 아니요 |
| 11/25 | 닫는 괄호 종류가 스택 맨 위와 달라도 스택 안쪽에 같은 종류의 여는 괄호가 있으면, 그 위의 여는 괄호들을 짝 없음으로 꺼내고 짝을 맞춘다 | 설계서 의사코드대로면 `int main() { if (a { } }`처럼 `)` 하나만 빠져도 오류가 3개로 번진다. 대체 시나리오 3의 결과(빠진 괄호 하나만 오류)를 지키기 위함. U-07~U-12 결과는 같고 O(n)도 그대로다 | 예 |
| 11/26 | 커서 앞뒤 글자가 모두 괄호이면 앞 글자(방금 입력한 괄호)의 짝을 먼저 강조한다. 테두리는 `border` 대신 `outline`으로 그린다. 괄호 굵게는 설계서대로 쓴다 | 설계서는 "커서 바로 앞이나 뒤"만 정했다. `border`는 글자 폭을 늘려 textarea와 어긋난다. 굵은 괄호 200개와 보통 괄호 200개의 폭이 같음을 Chrome(macOS, Courier New)에서 확인했다 | 아니요 |

## 편집 영역 글꼴 (11/22)

textarea와 색 표시 층(`<pre>`)을 겹쳤을 때 글자가 어긋나는지 Chrome(macOS)에서 비교했다. 탭·한글·영문이 섞인 14줄을 두 요소에 같은 CSS로 넣고, 줄마다 폭을 잰 뒤 두 층을 겹친 화면도 확인했다.

| 글꼴 | 영문 한 글자 | 한글 한 글자 | pre와 textarea 줄 폭 차이 |
|---|---|---|---|
| 지금 값 `Consolas, 'D2Coding', 'Courier New', monospace` (macOS에서는 Courier New) | 8.40px | 12.11px (영문의 1.44배) | 0.5px 미만(반올림 차이) |
| `Consolas, Menlo, monospace` (macOS에서는 Menlo) | 8.43px | 12.11px (1.44배) | 0.5px 미만 |
| 나눔고딕코딩 (웹 글꼴) | 7px | 14px (정확히 2배) | 0 |

- 세 글꼴 모두 두 층이 겹쳐 보였다. 같은 글꼴을 쓰는 한 어긋나지 않는다.
- 지금 값은 Windows에서는 Consolas, macOS에서는 Courier New로 보여 운영체제마다 모양과 폭이 다르다. 한글은 대체 글꼴(맑은 고딕, Apple SD Gothic Neo)로 그려져 영문 칸에 맞지 않는다.
- 나눔고딕코딩은 영문 7px, 한글 14px로 폭이 정수이고 한글이 정확히 두 칸이다. Windows와 macOS에서 같은 글꼴이 쓰이므로 두 환경의 화면 테스트 결과가 같아진다.

적용 방법: `@fontsource/nanum-gothic-coding` 패키지로 글꼴 파일을 앱에 포함한다(외부 서버에 요청하지 않음). `--font-code`를 `'Nanum Gothic Coding', Consolas, Menlo, monospace`로 바꾼다. 한글 글자 묶음은 필요할 때 내려받으므로, 처음 보는 글자는 잠깐 대체 글꼴로 보였다가 바뀐다. 두 층이 함께 바뀌므로 어긋나지는 않는다.

아직 확인하지 못한 것: Windows Chrome, macOS Safari. 11/24 Editor 연결 때 M-07로 확인한다.
